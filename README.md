# 四柱推命命式作成アプリ

生年月日と時刻から四柱推命の命式を計算するWebアプリケーションです。

## 概要
- 西暦・和暦（昭和・平成・令和）に対応
- 年柱・月柱・日柱・時柱の計算
- 大運の計算
- 真正生時の計算（経度差、均時差の反映）

## 技術スタック
- HTML
- CSS
- JavaScript（Vanilla JS）

## 注意事項
このプロジェクトはプログラミング学習初期（2022年）に最初に作成したアプリです。
現在のコーディングスキルとは異なる点があります。
